NetLogo syntax translator

Each line of code, translated. Command = does something. Reporter = returns a value.

Syntax rules

CodeMeaning
;Comment: rest of line ignored.
[ ... ]Block: group of commands or one reporter.
set x 5Prefix style: verb first, then inputs. No commas.
(list 1 2 3)Parentheses when a primitive takes more than its default number of inputs.
to name ... endDefine a procedure. Names are case-insensitive.

Program structure

CodeMeaning
to setup ... endDefine setup procedure (convention: initialize world).
to go ... endDefine go procedure (convention: one simulation step).
to my-proc [ a b ] ... endProcedure with inputs a and b.
clear-allObserver removes all agents, resets everything.
create-turtles 50 [ ... ]Observer makes 50 turtles; block runs once per new turtle.
reset-ticksSet time counter to 0 (usually last line of setup).
tickAdvance time counter by 1 (usually last line of go).
ticksReporter: current time counter value.

Declarations (top of Code tab)

CodeMeaning
globals [ score n ]Shared variables for whole model (observer-owned).
breed [ sheep a-sheep ]Turtle type: plural name = set, singular = one agent.
turtles-own [ energy ]Every turtle gets its own energy variable.
patches-own [ heat ]Every patch gets its own heat variable.
sheep-own [ wool ]Variable only for sheep breed.
directed-link-breed [ roads road ]Directed link type (has from/to).
undirected-link-breed [ edges edge ]Undirected link type (no direction).
links-own [ weight ]Every link gets its own weight variable.

ask: who runs the code

Code outside ask = observer. Turtle code must be inside ask turtles [ ].

CodeMeaning
ask turtles [ fd 1 ]Each turtle walks forward 1, one turtle at a time, random order.
ask turtle 0 [ set color red ]Only the turtle with who-number 0 turns red.
ask patches [ set pcolor green ]Every patch sets its color.
ask sheep with [ energy > 10 ] [ ... ]Only sheep with energy > 10 run the block.
selfReporter: the agent currently running this line.

Two ask blocks = two phases

CodeMeaning
ask turtles [ fd 1 ]
ask turtles [ set color red ]All turtles move, then all turtles turn red.
ask turtles [ fd 1 set color red ]Each turtle moves then turns red before the next turtle starts.

Variables

CodeMeaning
set energy 100Put 100 in energy.

let x 5Local variable x = 5 for this procedure/block only.

Control flow

CodeMeaning
if energy > 0 [ fd 1 ]Run block only when condition is true.
ifelse x > 0 [ ... ] [ ... ]If true run first block, else run second.
ifelse-value cond [ "yes" ] [ "no" ]Reporter: pick one of two values (like ternary).
repeat 10 [ fd 1 ]Run block 10 times.
while [ count turtles > 0 ] [ ... ]Run block while condition stays true.
stopExit current command procedure immediately.
report 42Inside to-report: return value and exit.

Code examples: with translations

Example 1: minimal setup / go

to setup
  clear-all
  create-turtles 20 [
    set color blue
    set energy 100
    fd random 10
  ]
  reset-ticks
end

to go
  ask turtles [
    if energy > 0 [
      set energy energy - 1
      fd 1
    ]
  ]
  tick
end
CodeMeaning
to setupDefine a setup procedure (runs once when you press Setup).
clear-allObserver wipes the world.
create-turtles 20 [ ... ]Make 20 turtles; block runs once per new turtle.
set color blueThis turtle turns blue.
set energy 100This turtle starts with energy 100.
fd random 10Walk forward 0–9 steps.
reset-ticksTime counter = 0.
endEnd of setup procedure.
to goDefine a go procedure (runs each tick when Go is on).
ask turtles [ ... ]Each turtle runs the block in turn.
if energy > 0 [ ... ]Only run when energy remains.
set energy energy - 1Spend 1 energy.
fd 1Walk one step.
tickAdvance clock one step.

Example 2: breeds and own variables

breed [ sheep a-sheep ]
breed [ wolves wolf ]
sheep-own [ grass-eaten ]
wolves-own [ hunger ]

to setup
  clear-all
  create-sheep 30 [ set color white set grass-eaten 0 ]
  create-wolves 5  [ set color black set hunger 0 ]
  reset-ticks
end

to go
  ask sheep [ eat-grass move-random ]
  ask wolves [ hunt ]
  tick
end

to eat-grass
  set grass-eaten grass-eaten + 1
  set color scale-color green grass-eaten 0 20
end

to move-random
  rt random 40 - random 40
  fd 1
end

to hunt
  let prey one-of sheep-here
  if prey != nobody [ ask prey [ die ] set hunger hunger + 1 ]
  fd 1
end
CodeMeaning
breed [ sheep a-sheep ]Declare turtle type: plural sheep, singular a-sheep.
breed [ wolves wolf ]Second breed: wolves / wolf.
sheep-own [ grass-eaten ]Every sheep has its own grass-eaten counter.
wolves-own [ hunger ]Every wolf has its own hunger counter.
to setupInitialize the model once.
clear-allRemove all agents and reset globals.
create-sheep 30 [ ... ]Observer makes 30 sheep; block runs per sheep.
set color whiteThis sheep is white.
set grass-eaten 0This sheep has eaten no grass yet.
create-wolves 5 [ ... ]Observer makes 5 wolves; block runs per wolf.
set color blackThis wolf is black.
set hunger 0This wolf starts with hunger 0.
reset-ticksClock back to 0.
to goOne simulation step.
ask sheep [ eat-grass move-random ]Each sheep runs both procedures in order.
ask wolves [ hunt ]Each wolf runs hunt.
tickAdvance time one step.
to eat-grassProcedure called by sheep.
set grass-eaten grass-eaten + 1Count one more grass eaten.
set color scale-color green grass-eaten 0 20Color shifts greener as grass-eaten rises (0–20).
to move-randomProcedure: wander one step.
rt random 40 - random 40Turn left or right up to 40°.
fd 1Walk forward one patch.
to huntProcedure called by wolves.
let prey one-of sheep-herePick one random sheep on my patch (or nobody).
if prey != nobody [ ... ]Only if a sheep was found on this patch.
ask prey [ die ]Tell that sheep to remove itself.
set hunger hunger + 1Wolf ate; increase hunger counter.

Example 4: if, ifelse, repeat, let

to go
  ask turtles [
    let step random 3
    ifelse energy > 20
      [ set color green ]
      [ set color red ]
    if energy > 0 [
      repeat step [ fd 1 ]
      set energy energy - step
    ]
  ]
  tick
end
CodeMeaning
to goOne simulation step.
ask turtles [ ... ]Each turtle runs the block in turn.
let step random 3Local variable = 0, 1, or 2.
ifelse energy > 20Test: is energy above 20?
[ set color green ]Then-branch: turn green.
[ set color red ]Else-branch: turn red.
if energy > 0 [ ... ]Move only when energy left.
repeat step [ fd 1 ]Walk forward step times.
set energy energy - stepPay energy equal to steps taken.
tickAdvance clock one step.

Example 6: links between turtles

to setup
  clear-all
  create-turtles 2 [
    setxy (who * 4) - 2  0
    set color blue
  ]
  ask turtle 0 [ create-link-to turtle 1 [ set color gray ] ]
  reset-ticks
end

to go
  ask turtle 0 [ fd 0.5 ]
  ask turtle 1 [ fd -0.5 ]
  tick
end
CodeMeaning
to setupCreate two turtles and link them.
clear-allStart from empty world.
create-turtles 2 [ ... ]Make 2 turtles; block runs per turtle.
setxy (who * 4) - 2 0Place turtles side by side using who number.
whoBuilt-in: this turtle’s ID (0, 1, …).

Example 7: to-report and procedure inputs

    if in-range? turtle 0 5 [ set color green ]

  tick
end

of agentEvaluate the bracketed expression as that agent.
to-report in-range? [ agent dist ]Reporter with two inputs: agent and distance.

distance agentBuilt-in: distance from me to that agent.
to goEach tick, check range and print distance.

Example 9: split go into smaller procedures

globals [ total-deaths ]
turtles-own [ energy ]

to setup
  clear-all
  set total-deaths 0
  create-turtles 50 [ set energy 100 set color green ]
  reset-ticks
end

to go
  move-turtles
  update-colors
  tick
end

to move-turtles
  ask turtles [
    if energy > 0 [
      fd 1
      set energy energy - 1
    ]
  ]
end

to update-colors
  ask turtles [
    ifelse energy > 50
      [ set color green ]
      [ set color red ]
    if energy <= 0 [
      set total-deaths total-deaths + 1
      die
    ]
  ]
end
CodeMeaning
globals [ total-deaths ]One shared counter for the whole model.
turtles-own [ energy ]Every turtle has its own energy value.
to setupInitialize world, turtles, and globals.
clear-allRemove all agents; reset globals to defaults.
set total-deaths 0Reset death counter to zero.
create-turtles 50 [ ... ]Make 50 turtles; block runs per turtle.
set energy 100Each turtle starts with 100 energy.
set color greenEach turtle starts green.
reset-ticksClock = 0.
to goOne step: delegate to sub-procedures, then tick.
move-turtlesCall procedure by name (no ask needed).
update-colorsCall second procedure by name.
tickAdvance time one step.
to move-turtlesSeparate procedure: handles movement only.
ask turtles [ ... ]Each turtle runs the block.
if energy > 0 [ ... ]Only move when energy remains.
fd 1Walk one patch forward.
set energy energy - 1Spend 1 energy for moving.
to update-colorsSeparate procedure: color + death logic.
ifelse energy > 50Test: is energy above 50?
[ set color green ]Then: healthy turtles stay green.
[ set color red ]Else: low-energy turtles turn red.
if energy <= 0 [ ... ]When energy is gone, count death and remove turtle.
set total-deaths total-deaths + 1Increment shared global before turtle dies.
dieRemove this turtle from the world.
